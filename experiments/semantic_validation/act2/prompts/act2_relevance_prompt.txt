Task: You are given one citation context in which the target citation is marked with #CITATION_TAG.
Judge the substantive relevance between the target citation and the current context.

Return JSON only. Do not output any text outside JSON.

Required JSON schema:
{
  "relevance": 0.0,
  "reason": "brief reason"
}

Relevance scale:
- 0.0-0.3: background citation, passing mention, weak relevance
- 0.3-0.6: moderate relevance
- 0.6-0.8: strong relevance
- 0.8-1.0: core dependency, method use, key comparison, result support, or other substantive citation

Requirements:
1. "relevance" must be a float between 0 and 1.
2. "reason" must be no more than 30 words.
3. If context is limited, still make the best judgment from the citation context and do not refuse.
